 Excel Sales Dashboard

 Project Overview
Created an interactive Sales Dashboard in Excel to track employee-wise and region-wise sales performance over five days.

 Key Features
- Employee-wise sales performance
- Region-wise sales analysis
- Total sales and target tracking
- Target achievement percentage
- Performance gap analysis
- Charts and PivotTables for reporting

 Tools Used
- Microsoft Excel
- PivotTables
- Charts
- Excel Formulas
- Data Analysis and Reporting

 Project Goal
The goal of this project is to monitor sales performance, compare employees, and identify progress toward sales targets.
